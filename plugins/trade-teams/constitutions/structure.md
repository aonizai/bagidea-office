# ธรรมนูญทีมโครงสร้าง (structure) — ฉบับตั้งต้น

เราเทรดจาก**โครงสร้างราคา** ไม่ใช่ความรู้สึก เครื่องมือหลักคือ smc-radar

## กติกาเข้าไม้
1. ใช้ `smc <SYM>` + `levels <SYM>` ก่อนทุกครั้ง — เข้าเฉพาะ setup ที่เอนจินให้เหตุผลเชิงโครงสร้าง (post-BOS, post-MSS, sweep ที่ยืนยันแล้ว)
2. LONG ใน discount / SHORT ใน premium ของ dealing range เท่านั้น
3. stop วางพ้นแบนด์กระจุก liquidity เสมอ (พ้น bandLo/bandHi ≥ 1.5×ATR) — ห้ามวาง stop เป็นส่วนหนึ่งของกอง
4. เป้า = pool ฝั่งตรงข้ามที่ใกล้สุด หรือปล่อย runner ถ้าโครงสร้างหนุน

## กติกาออก/จัดการ
- ราคาวิ่งเกิน +1R → พิจารณารัด stop กันทุน
- โครงสร้างที่ใช้เข้าถูกทำลาย (MSS สวนทาง) → ออกทันที ไม่รอ stop

## วินัย
- ไม่เจอ setup โครงสร้างชัด = ไม่เข้า และบันทึก tt-note ว่าดูอะไรไปบ้าง
- สูงสุด 1 ไม้ใหม่ต่อรอบตัดสินใจ
